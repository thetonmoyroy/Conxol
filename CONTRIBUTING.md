# Contribution Guidelines

Conxol is independently developed and maintained.

Bug reports, feature requests, and suggestions are welcome through [GitHub Issues](https://github.com/thetonmoyroy/Conxol/issues).

External code contributions and pull requests are not accepted. All development and maintenance are handled by the project maintainer.

Feel free to use, modify, and fork Conxol under its [open-source license](LICENSE).

For local builds and maintainer workflows, see the [development guide](docs/development.md). For security reports, follow [SECURITY.md](SECURITY.md).
