# Conxol 0.1.66

Windows x64 Microsoft Store submission build.

## Changes

- PPTP uses a 1450-byte MTU, subject to the peer's negotiated limit. Idle control polling no longer waits 10 ms before every GRE receive.
- Disconnected terminals show a Reconnect button and the R shortcut. Telnet/serial connection loss is distinguished from an active reconnect attempt.
- Network diagnostics open with MTR, followed by Ping and Port scan.
- MTR and Ping support up to eight independent tabs in total, with separate targets, network routes, settings, results and cancellation.
- Diagnostic results save automatically in the workspace. The Logs tab supports viewing, copying, exporting and clearing saved reports, with five-second live checkpoints and bounded retention.
