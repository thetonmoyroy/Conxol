# Conxol 0.1.54

Release build preparation for Windows x64, macOS Apple Silicon and Intel,
Linux x64, and Microsoft Store package version `0.1.54.0`.

## Changes

- Native `conxol-ping` replaces the system Ping executable.
- Native `conxol-mtr` replaces external MTR tools and shares the Ping ICMP transport.
- Ping/MTR elapsed time displays readable seconds, minutes and hours.
- Removed obsolete third-party MTR payloads and updated the Credits page.
- Sized macOS ICMP socket buffers for the full supported Ping payload range.

Native Ping/MTR currently support IPv4 on Windows and macOS. IPv6 and Linux
probing return an explicit unsupported message; there is no external fallback.
Windows Stop waits for an in-flight synchronous ICMP request to finish, up to
the selected timeout. macOS cancellation is polled during socket waits.

## Build targets

| Target | Package |
| --- | --- |
| Windows x64 | NSIS installer |
| Microsoft Store Windows x64 | MSIX, version 0.1.54.0 |
| macOS Apple Silicon | DMG |
| macOS Intel | DMG |
| Linux x64 | Debian package and AppImage |

Store identity and publisher remain the same as the existing Store package.
The MSIX is an unsigned Store upload; Microsoft signs accepted submissions.
Standalone installers are unsigned; Mac apps use ad hoc signatures and are not
notarized. Builds and validation receipts will be recorded after completion.
No Store submission or public release publication is part of the build step.
