# Conxol 0.1.53

Windows x64 and macOS Apple Silicon / Intel previews, published on 2026-11-06.

## Included features

This release brings together the compact terminal workspace, saved sessions and folder customization, SSH trust and authentication improvements, SFTP/SCP and remote editing, tunnels, command shortcuts, configuration generator, notes, custom highlighting, workspace protection and backup, FTP/TFTP tools, and native network diagnostics.

Recent source includes floating diagnostics, multi-host port scan progress and open-port output, native DNS reports, diagnostic text export, terminal layout/reconnect helpers and compact session action menus. See the README for the full feature list and protocol restrictions.

## Downloads

- `Conxol_0.1.53_x64-setup.exe`: existing locally built Windows x64 NSIS installer, version 0.1.53.
- `SHA256SUMS.txt`: SHA-256 integrity checksum for the Windows installer.
- `Conxol-0.1.53-macos-arm64.dmg`: macOS Apple Silicon disk image.
- `Conxol-0.1.53-macos-x64.dmg`: macOS Intel disk image.
- `SHA256SUMS-macos-arm64.txt` and `SHA256SUMS-macos-x64.txt`: Mac package checksums.
- GitHub-generated source archives: clean source snapshot with local assistant instructions and state excluded.

The Windows installer is unsigned. The macOS packages are ad hoc signed and not notarized. No Linux binary is published with this release. RDP remains experimental and excluded from the normal bundle. Clean-install and live-device acceptance are not established by publishing these packages.

## macOS build verification

Both packages were built on native GitHub-hosted macOS runners from source commit `41db18f`. The [successful build run](https://github.com/thetonmoyroy/Conxol/actions/runs/42252421649) passed frontend type checks, lint, unit tests, release-asset tests and version consistency checks. Each delivered DMG was mounted read-only; the app and VNC helper architectures were checked, the app passed deep strict code-signature verification, and its CLI reported the release version. The unshipped RDP helper was absent. SHA-256 manifests were checked again before release upload.

The builds do not replace GUI, clean-install or real-device testing. For future manual builds, use the macOS packages workflow; the separate publishing workflow accepts a successful build run ID and verifies package checksums before attaching assets to the matching release.

Preserved historical test documents and upstream demonstrations apply to their stated platform and version. See the security policy and third-party notices for additional boundaries and attribution.
