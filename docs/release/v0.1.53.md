# Conxol 0.1.53

Windows x64 preview, published from the current Conxol source on 2026-11-06.

## Included features

This release brings together the compact terminal workspace, saved sessions and folder customization, SSH trust and authentication improvements, SFTP/SCP and remote editing, tunnels, command shortcuts, configuration generator, notes, custom highlighting, workspace protection and backup, FTP/TFTP tools, and native network diagnostics.

Recent source includes floating diagnostics, multi-host port scan progress and open-port output, native DNS reports, diagnostic text export, terminal layout/reconnect helpers and compact session action menus. See the README for the full feature list and protocol restrictions.

## Downloads

- `Conxol_0.1.53_x64-setup.exe`: existing locally built Windows x64 NSIS installer, version 0.1.53.
- `SHA256SUMS.txt`: SHA-256 integrity checksum for the installer.
- GitHub-generated source archives: clean source snapshot with local assistant instructions and state excluded.

The installer is unsigned. No new macOS or Linux binaries are published with this release. RDP remains experimental and excluded from the normal bundle. The installer has not been executed as part of publication; clean-install, live-device and cross-platform acceptance are not established by publishing it.

Preserved historical test documents and upstream demonstrations apply to their stated platform and version. See the security policy and third-party notices for additional boundaries and attribution.
