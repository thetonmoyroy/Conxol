# Conxol 0.1.65

Published desktop release and Android ARM64 preview. The Windows x64 Microsoft Store submission package was built locally on 2026-11-10.

## Published downloads

The [GitHub release](https://github.com/thetonmoyroy/Conxol/releases/tag/v0.1.65) includes the Windows x64 EXE, macOS Apple Silicon and Intel DMGs, Linux x64 DEB and AppImage, Android ARM64 APK, and the unsigned Store-submission MSIX. SHA-256 manifests accompany the packages. The Store listing follows its own certification and release schedule.

Android retains the existing preview signing key. macOS packages are ad hoc signed and not notarized.

## Changes

- Saved Web sessions support optional PPTP routing; the PPTP Web browser requires Windows WebView2.
- Experimental RDP/VNC runtime support has been removed; legacy session metadata remains readable.
- Unreadable saved Telnet passwords allow interactive login; session editing supports replacement passwords.
- Unified app and terminal themes with eight additional palettes and Dark/Light previews.
- Theme and terminal color controls are in Settings > Appearance; syntax highlighting is in Settings > Terminal.
- Removed legacy portable vault controls and consolidated PIN/password information under Screen lock.
- Restored original Dark workspace colors and sidebar icon accents; improved terminal color picker layout.
