# Conxol 0.1.60

Windows x64 release built locally on 2026-11-08.

## Changes

- Add a configuration generator with named template fields, editable service and prefix rows, live output, clipboard copying, and text-file export.
- Save, update, and delete reusable templates. Saved templates retain command sections, field setup, and shared settings; service and prefix row values are excluded.
- Add combined interface, prefix-filter, import-policy, and BGP examples for Huawei, Cisco IOS XE, and Juniper Junos. Keep numeric-loop generation available.
- Add Juniper logical-system templates with an editable logical system per service and scoped interfaces, policies, routing options, and BGP.
- Support IPv4 CIDR input and numeric or slash prefix lengths in subnet-mask fields. Convert automatically to dotted masks for Huawei/Cisco and prefix lengths for Junos.
- Update peer IPs automatically when local addressing changes. Support manual peer overrides and an Auto control to restore automatic addressing.
- Add one shared Remote BGP AS with explicit per-service overrides. Fix existing row values incorrectly preventing shared-AS updates.
- Make the generator more compact: interface inputs first, separate aligned BGP inputs, collapsed command editors, and full-width results at the bottom.
- Use RFC 5737 documentation IP addresses and RFC 5398 documentation ASNs in built-in examples.
- Move the development server to port 15420 and align Vite, Tauri, and the development connection policy to avoid Windows' reserved port 1420.
