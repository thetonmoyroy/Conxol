# Conxol 0.1.56

## Changes

- Fix packaged terminal formatting: keep the startup screen stylesheet external so SSH, Telnet and console terminals retain monospace fonts, column spacing and ANSI colors under the packaged security policy.
- Add optional Telnet username/password auto login and explicit system credential-store saving. Session files contain credential references, never passwords.
- Preserve pending serial reads across keyboard input to prevent lost console output. Send device-compatible Backspace and align bare-LF console output.
- Simplify Console setup to serial port and baud rate, default to 9600 baud, and move advanced options into a Bookmark-style disclosure. New console connections are not saved.
- Match dropdown colors to the app theme, hide unknown serial-port types, and show operating-system-specific port hints.
- Add Sessions > New session, dismiss routine notices automatically, and remove connection-success and terminal-bell popups.
- Show an animated startup console while the workspace or PIN screen loads, with a dark native background to prevent the initial white flash. Conxol Home text remains static.
- Expand TCP checks with address resolution, per-attempt timing, endpoint and socket details, measured local socket settings, and clearer errors. Default TCP checks to port 80 while retaining port 22 for SSH inspection.

## Downloads

- Windows x64: NSIS installer.
- Linux x64: Debian package and AppImage.
- macOS: Apple Silicon and Intel DMGs.
- SHA-256 manifests accompany the GitHub installers.

An unsigned Microsoft Store submission MSIX is prepared separately using the existing Store identity. Creating the MSIX does not submit it to Microsoft. Experimental RDP remains excluded; the native VNC helper is included. macOS packages are ad hoc signed, not Developer ID signed or notarized.

## Validation

Frontend type checks, lint and unit tests; release-artifact validation; isolated serial, Telnet, network and diagnostics tests; native packaging checks and package checksums. Clean-machine installation, Store certification/WACK, and live-device acceptance are not claimed.
