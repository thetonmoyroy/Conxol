# Conxol 0.1.55

> Historical references to RDP/VNC describe earlier versions. Both implementations,
> helpers and related commands have been removed; old saved entries remain readable
> but cannot connect. See the current removal decision in `docs/adr/0036-retire-remote-desktop-support.md`.

Windows x64 release artifacts prepared on 2026-11-07.

## Changes

- Navigate terminal tabs with the mouse Back and Forward buttons.
- Organize saved devices in nested folders, including drag-and-drop folder moves.
- Choose whether the tab + button opens a new-session form or the saved-session browser in General settings.
- Browse saved devices with search, a folder sidebar, Favorites and Recent views, protocol filters, and sorting.
- Use a more compact new-session form.
- Prevent repeated SSH connection submissions from opening duplicate tabs, including unsaved devices.
- Disable writing assistance on username, credential, password, passphrase, and PIN fields.

## Windows packages

- `Conxol-0.1.55-windows-x64.exe`: GitHub download, NSIS installer.
- `Conxol_0.1.55.0_x64.msix`: unsigned Microsoft Store submission package.
- SHA-256 checksum files accompany both packages.

These packages include the native VNC helper. Experimental RDP remains excluded from normal bundles.

The MSIX uses the existing Store identity and is unsigned for Store submission. Store certification, WACK, clean-machine installation, and live-device acceptance remain separate checks. Generating these artifacts does not publish a GitHub release or submit the package to Microsoft.
