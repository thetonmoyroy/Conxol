# Conxol 0.1.67

Windows x64 Microsoft Store submission build, package version `0.1.67.0`.

## Changes

- New MTR tabs default to a maximum of 30 hops.

- Terminal search recognizes complete MAC addresses in six formats: six pairs
  or three groups of four hexadecimal digits separated by dots, colons or
  hyphens. Searching one format finds all six regardless of hexadecimal case.
- SFTP files can open directly in a selected external text editor. The editor
  executable preference persists across application restarts.
- External saves upload quietly through the existing revision-checked SFTP
  save path. No persistent editing panel or polling-related button flashing.
- Notepad++ uses a dedicated window. Closing it triggers a final file check
  and upload before cleanup. Conflicts and upload failures preserve the local
  copy and display recovery controls. Editors that hand files to an existing
  process remain watched silently until app exit.
- Store packaging includes transparent taskbar icon variants for light and dark
  themes and a Windows resource index, removing the fallback accent-color tile.

## Validation

Frontend unit tests, lint and type checks passed. Four isolated native external
editor tests and seven release-artifact tests passed. Cargo, frontend, Tauri
and Android versions match; all three Cargo lockfiles passed locked metadata
validation. The frontend production build and optimized native release build
passed. The initial native build needed the installed NASM directory added to
the build process PATH.

MakeAppx manifest validation and package round-trip checks passed. Independent
ZIP inspection verified all 21 payload hashes, the executable's equality with
the current release binary, Store identity, publisher, architecture and version.
All 12 taskbar icon variants have the expected pixel dimensions and transparent
corners; MakePri indexed their variants in `resources.pri`. The release
executable reports `Conxol 0.1.67`. Installed taskbar appearance has not been
tested in this build.
