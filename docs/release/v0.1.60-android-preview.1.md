# Conxol Android preview 1

> Historical references to RDP/VNC describe earlier versions. Both implementations,
> helpers and related commands have been removed; old saved entries remain readable
> but cannot connect. See the current removal decision in `docs/adr/0036-retire-remote-desktop-support.md`.

First signed Android preview, based on Conxol 0.1.60.

## Download

- ARM64 APK for Android 7.0/API 24 or newer.
- Version name: `0.1.60-android-preview.1`; version code: `1061`.
- Optimized release build, signed with the persistent Conxol Android preview
  certificate. The APK is not debuggable.
- Verify the APK using the accompanying SHA-256 checksum and signing certificate.

## Included

- Rust/Tauri Android port with a touch layout and original Conxol launcher icon.
- Saved devices, recent devices, Notes, and sidebar toggles/outside-tap dismissal.
- SSH terminal and SFTP remote browsing/operations, plus Telnet and sandbox shell.
- Router configuration templates with saved templates, editable inputs, and live output.
- Native IPv4 Ping and MTR using Android ICMP sockets and TTL/error-queue handling.
- Horizontal application-menu scrolling and full-width SSH settings on phones.
- RDP/VNC options are hidden because their desktop helpers are not ported.

## Preview limitations

- Android secure password storage and shared-storage upload/download pickers are
  not implemented. Workspace backup import/export is unavailable on Android.
- No foreground service yet guarantees connections while the app is backgrounded.
- IPv6 Ping/MTR, Android RDP/VNC, and desktop serial adapters are not supported.
- Authenticated SSH/SFTP interoperability and routed MTR hops still need physical
  device testing. Emulator checks covered startup, session storage, PIN state,
  clipboard, TCP, SSH host-key inspection, sandbox shell, config generation,
  sidebar/layout interactions, and native Ping/MTR loopback probes/cancellation.

## Installing over older local test APKs

Older debug APKs use a different signing certificate. Android cannot update them
directly with this signed release. Uninstalling a debug APK removes its local
app data; preserve any needed information first. Future previews signed with
this release key will support normal updates in place.

The stable Windows/macOS/Linux release remains v0.1.60.
