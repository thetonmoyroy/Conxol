Looking for a few friends to test Conxol! 🧪💻

I’ve been working on Conxol, a desktop workspace for managing terminals, remote sessions and everyday network tasks. It builds on the open-source MobaRust project, with my own interface changes and added features.

What you can try:
• SSH sessions and SFTP file browsing
• Saved hosts, folders, favorites, and custom icons/colors
• Terminal tabs, split panes, search, and syntax highlighting
• A command generator for repetitive network configurations
• Live Ping with interval and packet-size controls
• Live MTR with packet-loss and latency statistics
• TCP/UDP port-range scanning and DNS lookups
• Command shortcuts, macros, notes, and FTP/TFTP tools

This is an early Windows test build. I’d love feedback from friends who work with networks, servers, or ISP operations.
