CONXOL / GETTING STARTED

Your first connection.

Conxol is an open-source SSH client and network workspace for Windows, macOS and Linux. Start with a packaged release, or build the desktop app from source.

Install Conxol

  • Windows: use the Microsoft Store listing or the Windows x64 installer. The standalone installer is unsigned. Microsoft Edge WebView2 Runtime is required; Store availability has its own release schedule.
  • macOS: choose Apple Silicon or Intel, open the DMG, and move Conxol to Applications. The packages are ad hoc signed and not notarized.
  • Debian/Ubuntu: install the x64 DEB through your package manager. Other Linux desktops can use the AppImage; WebKitGTK 4.1 and FUSE may be required.
  • Android preview: ARM64 APK for Android 7+. Use the signed preview from the release page. Older debug APKs use a different certificate and may require uninstalling before installation; back up your data first.

Download installers only from the 0.1.65 release page or the Microsoft Store listing. Compare standalone downloads with the platform's SHA-256 manifest.

Connect with SSH

  1. Open a new session and choose SSH.
  2. Enter the host, port and username. Configure authentication and jump hosts if needed.
  3. Review an unknown host's fingerprint against a trusted source before accepting it.
  4. Use terminal tabs and splits, the remote file browser, and tunnels as your task requires.

Supported private keys, interactive password entry, OpenSSH agent and Windows Pageant are available. RSA private-key authentication is not supported. RSA-SHA2 server host-signature verification is supported.

Customize and organize

Settings > Appearance controls unified workspace and terminal themes with palette previews. Settings > Terminal contains syntax highlighting. Screen lock contains the 4–12 digit numeric PIN controls. Drag a saved session onto a terminal for a new connection in a right split. Saved Web sessions support optional PPTP routing; the PPTP Web browser requires Windows WebView2.

Generate network configurations

Open Generator, choose a Huawei, Cisco IOS XE or Juniper Junos template, then fill the interface and service rows. Juniper logical-system templates are available too. CIDR input converts to the vendor's addressing format; automatic peer addressing can be overridden.

Set one shared remote BGP ASN, enable overrides for individual services, and edit prefix or route policies. Review the full result before copying or exporting it. The generator produces text and does not configure a device. Built-in samples use documentation-only addresses and ASNs.

Know the limits

  • Native Ping/MTR currently support IPv4 on Windows, macOS and the Android preview. Linux and IPv6 probing are not implemented.
  • RDP/VNC support has been removed. Existing saved entries are preserved as unsupported. Telnet is unencrypted.
  • FTP/FTPS client support depends on system curl capabilities. X11 forwarding requires an external X server.
  • Release-package checks do not replace clean-machine or real-device acceptance testing.

Build from source

Use Rust stable 1.90+, Node.js 22, pnpm 10 and the native Tauri prerequisites for your operating system.

git clone https://github.com/thetonmoyroy/Conxol.git
cd Conxol
pnpm install --dir apps/desktop --frozen-lockfile
pnpm --dir apps/desktop tauri dev
