05 / A FEW GOOD ANSWERS

Before you connect.

Read the getting-started guide ↗

Is Conxol a MobaXterm alternative?

Conxol is a free, open-source desktop option for SSH, file transfers, tunnels, serial access and network tools on Windows, macOS and Linux. Its feature set and platform support differ from MobaXterm; it is not a drop-in replacement for every workflow.

Does it send configurations to my routers?

No. The generator produces editable configuration text. Review it, then copy or export it for your own deployment process. Built-in examples use documentation-only IP addresses and ASNs.

Which platforms and protocols have limits?

Native Ping/MTR currently support IPv4 on Windows, macOS and the Android preview; Linux and IPv6 probing are not implemented. RDP/VNC support has been removed; old saved entries remain readable but cannot connect. Telnet is unencrypted. See the documentation for authentication and installation limits.

Can I build it or report an issue?

Yes. The development guide covers local builds. Report bugs and request features through GitHub Issues. External code contributions and pull requests are not accepted.
